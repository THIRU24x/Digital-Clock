🕐 Digital Clock built using HTML, CSS, and JavaScript. This project displays the current time in real time with a clean and responsive user interface. It uses JavaScript to dynamically update the clock every second, making it a simple and practical project for learning DOM manipulation, JavaScript functions, and real-time updates.

🚀 Technologies Used: HTML5 • CSS3 • JavaScript
🎯 Purpose: Built to strengthen JavaScript and frontend development skills.
